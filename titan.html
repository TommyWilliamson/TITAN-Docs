    Docs#

    TransatmospherIc flighT simulAtioN (TITAN) - A python code for multi-fidelity and multi-physics simulations of access-to-space and re-entry.

    Main Functions#

    __main__ module.

    titan.__main__.loop(options=[], titan=[])#

    Advance the TITAN simulation through its configured iterations.

    Each iteration applies fragmentation checks, dynamics, and enabled physics/output routines to the simulation state.

    Parameters:

    • options (Options) – Simulation configuration and runtime options.

    • titan (Assembly_list) – Simulation state containing assemblies and iteration data.

    titan.__main__.main(
    filename='',
    postprocess='',
    filter_name=None,
    emissions='',
    )#
    TITAN main function
    param filename:

    Name of the configuration file, defaults to “”

    type filename:

    str

    param postprocess:

    Postprocess method. If specified, TITAN will only perform the postprocess of the already obtained solution in the specified output folder. The config file still needs to be specified. Defaults to “”

    type postprocess:

    str, optional

    param filter_name:

    Assembly filter for postprocessing, defaults to None

    type filter_name:

    str, optional

    param emissions:

    Option to run emmisions postprocessing, defaults to “”

    type emissions:

    str, optional

    Returns:

    options, titan

    Return type:

    Options, Assembly_list
