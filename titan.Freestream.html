    Load or select the configured atmospheric model.

    Parameters:

    • name (str) – Atmospheric model name (for example, 'PYMSIS' or 'GRAM').

    • options (Options) – Simulation options used to cache model interpolation data.

    • epoch (datetime.datetime or None) – Optional epoch for time-dependent atmospheric models.

    Atmospheric data provider and its species ordering.
