    Create a component and append it to this collection.

    Parameters:

    • filename (str) – Mesh or geometry filename for the component.

    • file_type (str) – Component category, such as a primitive or joint.

    • inner_stl (str) – Optional filename for an inner surface mesh.

    • id (int) – Identifier argument retained for API compatibility; the collection assigns its own sequential identifier.

    • binary (bool) – Whether mesh input should be read as binary.

    • trigger_type (str) – Failure or fragmentation trigger mode.

    • trigger_value (float) – Threshold associated with the trigger mode.

    • fenics_bc_id (int) – Boundary-condition identifier for FEniCS.

    • material (str) – Material name used to initialize the component.

    • temperature (float) – Initial component temperature in kelvin.

    • options (Options) – Simulation configuration.

    • global_ID (int) – Global identifier associated with the source object.

    • bloom_config (list) – Boundary-layer mesh configuration values.

    • alpha (float) – Component-specific scaling parameter.

    • mixture (str or None) – Optional gas-mixture name for ablation products.

    • mass_fractions (list or None) – Initial species mass fractions.

    • species (list or None) – Species names associated with the mixture.

    • explosive_parameters (dict or None) – Optional explosive-fragmentation settings.
