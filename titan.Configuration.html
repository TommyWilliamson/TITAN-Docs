    SoI_rad#

    [float] Raytrace sphere of influence radius

    heat_model#

    [str] Name of the heatflux model to be used

    knc_heatflux#

    [float] Value of the continuum knudsen for the heatflux computation

    knc_pressure#

    [float] Value of the continuum knudsen for the pressure computation

    knf#

    [float] Value of the free-molecular knudsen

    mixture#

    [str] Mixture file name

    recalculate_Aref#

    [bool] Whether to recalculate the reference area at each ray tracing step (good for accurate Cd/Cl prediction)

    recalculate_Lref#

    [bool] Whether to recalculate the reference length at each ray tracing step (good for high aspect ratio tumbling)

    class titan.Configuration.configuration.Trajectory(
    altitude=0,
    gamma=0,
    chi=0,
    velocity=0,
    latitude=0,
    longitude=0,
    )#

    Bases: object

    Represent the user-defined trajectory state.

    Variables:

    • altitude – Geodetic altitude in metres.

    • gamma – Flight-path angle in radians.

    • chi – Heading angle in radians.

    • velocity – Velocity magnitude in metres per second.

    • latitude – Geodetic latitude in radians.

    • longitude – Geodetic longitude in radians.

    altitude#

    [meters] Altitude value.

    chi#

    [radians] Heading Angle value.

    gamma#

    [radians] Flight Path Angle value.

    latitude#

    [radians] Latitude value.

    longitude#

    [radians] Longitude value.

    velocity#

    [meters/second] Velocity value.
